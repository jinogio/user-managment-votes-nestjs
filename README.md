# User Management & Voting API

A NestJS-based backend application for managing users and voting logic. Built with scalability and modularity in mind.

## Features

- User registration and login (JWT-based)
- Role-based access control
- Voting functionality
- Swagger API documentation
- MongoDB integration via Mongoose

## Technologies Used

- Node.js / NestJS
- MongoDB / Mongoose
- TypeScript
- Swagger
- Mocha / Chai

## Getting Started

### Prerequisites

- Node.js (v16+)
- MongoDB (local or remote)

### Installation

`bash
git clone https://github.com/jinogio/user-managment-votes-nestjs.git
